# 长颈鹿骑自行车 · SVG 动态原型

一只骑自行车的长颈鹿。**动画 100% 由 CSS/SVG 时间轴驱动，JS 只调参数、只读数。**

## 运行

直接双击打开 `index.html`，或任意静态服务器：

```bash
python -m http.server 8613   # → http://localhost:8613/
```

推荐 Chromium / Firefox 最新版（腿部关键帧使用 CSS `d: path()` 插值）。

## 相位锁定原理

所有旋转件共用同一个 `@keyframes spinFull`，只让周期成严格整数比，倍率变化时比值不变：

| 部件   | 周期 | 关系                          |
| ------ | ---- | ----------------------------- |
| 车轮/飞轮 | 2s   | 30 rpm @ ×1                   |
| 曲柄/牙盘/踏板 | 4s   | 15 rpm，传动比 16T:8T = 2.0  |
| 链条   | 4s   | 每圈前进 16×节距 = 恰好 16 个虚线周期 |
| 后腿   | 4s   | 24 帧 IK 关键帧，脚逐帧落在曲柄圆上 |
| 远侧件 | 同上 | `animation-delay: -2s` 锁定 180° 相位 |

## 停车 / 下车 / 驻车（点击"⏸ 停车"或空格）

1. **减速滑行**：JS 只设一个目标倍率（剩余曲柄时间 ÷ 1.4s，钳制在 0.2–1.35），
   整条时间轴等比减速，全部相位关系不变；
2. **规范相位冻结**：rAF 只读 `currentTime` 检测曲柄过 0°——到位瞬间加 `.parked` 类，
   `.ride` 动画冻结在规范相位（近踏板 0°/远踏板 180°）；
3. **下车（纯 CSS）**：`dismount*` 一次性关键帧接管——身体挪到车旁、后腿跨过车架落地、
   双手松把垂下；0% 帧与规范相位姿态逐像素一致，**切换无跳变**；上车直接反向播放同一组关键帧；
4. **支架**：`kickDown` 带过冲回弹放下（驻车 1.15s 后），上车时 `kickUp` 收起；
5. **驻车呼吸**：呼吸/摆尾/转头慢速待机动画继续，云仍在飘，车速读数如实归零。

上车序列以 `animationend` 为主、3.1s 超时兜底，结束时腿部恰为骑行 0% 姿态，
循环动画从规范相位 0 无缝接续，齿轮相位 Δ 始终 0.00°。

链条按真实几何生成（`tools/generate-leg-keyframes.mjs`）：闭环 **44 节**，节距 `p=10.0459px`，
牙盘/飞轮齿距与链节距相等（弧段 12 节 + 直段 32 节），齿盘初相旋转 `4.58°`
使齿与链节间隙在切点对齐 —— 齿、链、轮的相位在任意倍率、任意时刻保持数学锁定。

## JS 职责（main.js）

- **调速**：`document.getAnimations()` 统一写 `playbackRate`（同步生效，currentTime 连续无相位跳变）；
- **暂停**：统一 `pause()/play()`（空格键同效）；
- **读数**：以动画 `currentTime` 为唯一时间源，换算车速 / 踏频 / 轮速 / 里程，
  并实时校验 `θ轮 = 2·θ曲柄 (mod 360°)`，偏差恒为 0.00°（面板显示"已锁定"）。

## 文件

- `index.html` — SVG 场景与控制面板
- `style.css` — 全部关键帧动画（含生成的腿部/链条关键帧）
- `main.js` — 仅参数与读数
- `tools/generate-leg-keyframes.mjs` — 腿部 IK 与链条啮合几何生成器（产物已内联）
